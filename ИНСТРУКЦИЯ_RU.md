# AuraMusic 26.3 — инструкция

Это **новый самостоятельный мод**, а не переименованный Overtune. Внутри новый исходный код, лицензия MIT и готовый GitHub Actions workflow.

## Что умеет

- Клавиша **M** открывает меню плеера.
- Вкладки **ALL / DISCS / LOCAL WAV / FAVORITES**.
- Встроенные музыкальные звуки и пластинки Minecraft.
- Локальные файлы в формате **WAV (PCM)**, до 60 МБ на файл.
- Избранное, перемешивание, повтор, пауза, следующий/предыдущий трек.
- Перемотка WAV ±10 секунд; регулировка громкости WAV.
- Сохранение настроек в `.minecraft/config/auramusic.properties`.

**Ограничения:** MP3 и OGG ещё не поддерживаются как пользовательские файлы; локальный звук выводится через Java Sound; при возобновлении музыки Minecraft трек начинается заново. Сборка/запуск в настоящем Minecraft пока не проверены.

## Загрузка на GitHub

1. Создай **пустой** репозиторий, например `AuraMusic-26.3`.
2. Распакуй архив на компьютере.
3. На странице нового репозитория нажми **uploading an existing file**.
4. Перетащи **весь состав папки** `AuraMusic-26.3`, а не внешний ZIP и не папку целиком. В корне должны лежать `build.gradle`, `gradle.properties`, `src` и `.github`.
5. Нажми **Commit changes**.
6. Зайди в **Actions → Build AuraMusic 26.3**. Сборка должна стартовать автоматически после загрузки файлов.
7. Если сборка зелёная, открой запуск → внизу **Artifacts → AuraMusic-26.3-JAR**. Установи JAR из архива в `mods`, но **не `-sources.jar`**.
8. Если сборка красная, открой `build → Build mod` и сохрани текст ошибки.

## Запуск игры

- Minecraft Java Edition **26.3**, Fabric Loader **0.19.5+**, **Fabric API для 26.3**, Java **25**.
- Помести готовый JAR в `mods` выбранного профиля.
- После запуска мира нажми **M**.
- Для своей музыки положи PCM WAV в `<папка игры>/auramusic/tracks/`, потом нажми **SCAN** в плеере.
- Для обычного лаунчера Windows часто используется `%APPDATA%\.minecraft\auramusic\tracks`, но сторонние лаунчеры используют отдельные папки игры.

### Почему здесь нет готового собранного JAR?

В рабочей среде этой версии проекта отсутствуют JDK 25 и доступ к Maven-зависимостям Fabric. Поэтому сейчас возможны проверка исходников на Java-синтаксисе с тестовыми API-заглушками и тест настроек, но не реальная сборка Fabric-мода. Настоящую компиляцию выполнит GitHub Actions. Это **экспериментальная альфа-версия**.
